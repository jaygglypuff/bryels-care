Getting the materials is done on the **Materials list** of the batch (see "Get the materials for a batch"). It scans labels and moves stock when your site's settings ask for it. The older "Get materials by scanning" screen now opens the production orders.

## What this screen shows

This screen ("Lots and sheets") shows, for one batch:

1. Which lots are set aside for each ingredient and where they went.
2. **QA substitution**: a QA person replaces a set-aside lot with another lot of the same material, with a reason (a controlled exception). A different material is never allowed.
3. **Print weighing sheet** and **Print traveler** (paper copies, if your site keeps paper).

## Next

The green button at the top opens the next production screen of the batch (Get materials, or Continue this batch).
