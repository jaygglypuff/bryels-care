Many dropdowns get their choices from **Management → Master data → Lists**: product families, material categories, customer types and supplier categories. The owner and the system administrator can change them. Everyone else can look.

## Add a choice

1. Open **Management → Master data → Lists**.
2. Find the list, for example **Material categories**.
3. Type the new name under **New option**, for example "Clays".
4. Tap **Add option**. It appears at the end of the list and in the dropdown straight away.

## Rename or move a choice

1. Tap **Change** under the choice.
2. To rename, type the new name and tap **Save name**. Records that already use it show the new name.
3. To change the order in the dropdown, tap **Move up** or **Move down**.

## Stop using a choice

1. Tap **Change**, then **Turn off**. It is no longer offered in the dropdown.
2. Records that already use it keep it. Tap **Turn on** to offer it again.
3. **Delete** is only there for a choice nobody has used yet, for example a typing mistake.

## Lists that are not here

- Reason codes and units of measure have their own screens. The Lists page links to them.
- Complaint categories, severity levels and expense categories are under **Settings**, because a change needs a second person's approval.
- Statuses, location types and material class are fixed. The program depends on them.
